ChaseLab · beta de pruebas

Este paquete todavía no está firmado con Developer ID ni notarizado. Es una entrega de pruebas, no una versión certificada para producción.

Instala ChaseLab en Aplicaciones. Incluye CL Player, CL Bumper, CL Outliner, CL Outline Src, CL Wiper y CL Random.

  1. Guarda y cierra Arena.
  2. Abre ChaseLab desde Aplicaciones.
  3. En el menú de ChaseLab, elige «Instalar efectos en Arena…» y selecciona Extra Effects dentro de Documentos/Resolume Arena.
  4. Abre Arena y busca los nombres que comienzan por CL.

Los efectos anteriores con los mismos identificadores se respaldan al actualizar. No se borran proyectos, envolventes, presets ni complementos de terceros. Si usabas ChaseLab Live desde otra carpeta, cierra esa copia antes de abrir ChaseLab.

macOS 13 o posterior. Editor Apple Silicon o Intel según el paquete; efectos universales. Intel es experimental hasta probarlo en un Mac Intel real. Resolume Arena 7.23.0 es la versión comprobada; otras versiones requieren pruebas. Windows todavía no está disponible.
