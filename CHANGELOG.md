# Changelog

## 0.15.0-beta.1

- Consolidated current editor and six FFGL variants into one source repository.
- Standardized visible names to ChaseLab / CL Player / CL Bumper / CL Outliner / CL Outline Src / CL Wiper / CL Random.
- Preserved app identity, plugin FFGL IDs, parameter names and bundle filenames.
- Added a per-user plugin installation menu with payload hashes, identity checks and backups.
- Added Apple Silicon and experimental Intel package builders, tests and Apache-2.0 licensing; preserved the FFGL BSD license.
- Kept prior functional implementations, including the Filled animated corner correction. Public-distribution signing/notarization and physical Intel validation remain pending.
